# Antigravity-first-project
I wanted to try out Antigravity's capabilities with a simple project and worked on a Pomodoro Timer according to this tutorial here: https://www.youtube.com/watch?v=-0Irz8G0PEE
The concept is as simple as can be and does not complicate it with any sort of backend, authentication, storage, etc. just a simple 25 minute timer. 
My goal here is to replicate the functionality as shown in the tutorial video and try my hand at how advanced Antigravity can be.
Positives: Super intuitive and the steps from implementation, planning, execution, testing and approval are all very easy to follow
Negatives: The agent still can get confused easily and I had to stop and restart commands multiple times even for a simple task like this especially when it came to timer logic.
Overall, the IDE is impressive but do be careful on how much complexity you give the agent since it can get confused and get stuck easily. I'll be trying my hand at a slightly more complex application soon.
